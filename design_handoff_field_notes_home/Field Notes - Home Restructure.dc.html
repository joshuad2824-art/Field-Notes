Turn 3 · the pen

Nine hands, none of them script

Every one of these is printed handwriting — letters that stand apart — so nothing turns into looping cursive. Same three lines, same dark teal leaf, same dot grid, each set at the size that keeps the 28px line rhythm the app is built on. Caveat is first so you can see what you'd be giving up.

Worth saying: --font-pen already asks for Linotype Feltpen first and only falls back to Caveat — so if you license that one, the app picks it up with no change. Everything below is a free stand-in for it.

Turn 1 · home restructure

Two homes, and the page at rest

The handwriting, the hand-drawn highlighter, the dark teal page and the dot grid all stay exactly as they are — none of that is in question. What changes is everything around them: the brown bar is gone, the date does the work of a header, and the big monitor gets filled by a third column instead of a stretched button. Nothing here has been pushed anywhere.
